# WINDOW FUNCTIONS 


SQL WINDOW FUNCTIONS

1. RANKING FUNCTIONS

1. ROW_NUMBER()

Definition: Assigns a unique sequential number to each row based on the specified order.

Syntax:
ROW_NUMBER() OVER (
    [PARTITION BY column_name]
    ORDER BY column_name
)

2. RANK()

Definition: Assigns a rank to each row based on the specified order. Rows with equal values receive the same rank, and gaps appear in the ranking sequence.

Syntax:
RANK() OVER (
    [PARTITION BY column_name]
    ORDER BY column_name
)

3. DENSE_RANK()

Definition: Assigns a rank to each row based on the specified order. Rows with equal values receive the same rank, without gaps in the ranking sequence.

Syntax:
DENSE_RANK() OVER (
    [PARTITION BY column_name]
    ORDER BY column_name
)


2. AGGREGATE WINDOW FUNCTIONS

1. MAX()

Definition: Returns the maximum value within the specified window.

Syntax:
MAX(column_name) OVER (
    [PARTITION BY column_name]
)

2. MIN()

Definition: Returns the minimum value within the specified window.

Syntax:
MIN(column_name) OVER (
    [PARTITION BY column_name]
)

3. AVG()

Definition: Returns the average value within the specified window.

Syntax:
AVG(column_name) OVER (
    [PARTITION BY column_name]
)

4. SUM()

Definition: Returns the sum of values within the specified window.

Syntax:
SUM(column_name) OVER (
    [PARTITION BY column_name]
)

5. COUNT()

Definition: Returns the number of rows or non-NULL values within the specified window, depending on the argument.

Syntax:
COUNT(*) OVER (
    [PARTITION BY column_name]
)

COUNT(column_name) OVER (
    [PARTITION BY column_name]
)


3. OFFSET FUNCTIONS

1. LAG()

Definition: Retrieves a value from a preceding row within the specified window without requiring a self-join.

Syntax:
LAG(
    column_name [, offset [, default_value]]
) OVER (
    [PARTITION BY column_name]
    ORDER BY column_name
)

2. LEAD()

Definition: Retrieves a value from a subsequent row within the specified window without requiring a self-join.

Syntax:
LEAD(
    column_name [, offset [, default_value]]
) OVER (
    [PARTITION BY column_name]
    ORDER BY column_name
)


IMPORTANT NOTES

1. OVER() defines the window of rows used by the function.
2. PARTITION BY divides rows into groups and is optional.
3. ORDER BY specifies the order of rows within the window.
4. For ranking and offset functions, ORDER BY is required to define the intended row order.
5. For aggregate window functions, adding ORDER BY can change the calculation to a running or cumulative result.
6. Square brackets [ ] indicate optional syntax. Do not type them in the actual SQL statement.
