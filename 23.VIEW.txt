What is a VIEW?

  * A VIEW is a virtual table created using a SQL query. 
  * It retrieves data from one or more underlying tables.
  * A normal view stores the SQL query definition, not a separate copy of the underlying table data.

WHY DO WE USE VIEWS?

1. Security - Restrict access to specific columns or rows.
2. Simplicity - Simplify complex SQL queries.
3. Reusability - Reuse queries without rewriting them.
4. Data abstraction - Hide the complexity of underlying tables.
5. Customized presentation - Display specific data to different users.

   TYPES OF VIEWS
      * NON MATERIALIZED VIEW

 NON MATERIALIZED VIEW
 ----------------------
    * A non-materialized view is a virtual table created using a SQL query.
    * It stores the query definition, not a separate copy of the query results.
         1) SIMPLE VIEW
         2) COMPLEX VIEW

A. SIMPLE VIEW

A simple view is based on a single table and does not contain group functions or grouping.

Example:

CREATE VIEW EMP_SIMPLE_VIEW AS
SELECT EMPNO, ENAME, SAL
FROM EMP;

Features:
1. Based on one table.
2. Does not contain GROUP BY or aggregate functions.
3. May support INSERT, UPDATE and DELETE, subject to Oracle's updatability rules.

SYNTAX TO CREATE A VIEW
------------------------

CREATE VIEW view_name AS
SELECT column1, column2
FROM table_name;

Example:

CREATE VIEW EMP_VIEW AS
SELECT EMPNO, ENAME, SAL
FROM EMP;

HOW TO RETRIEVE DATA FROM A VIEW

SELECT EMPNO, ENAME, SAL
FROM EMP_VIEW;

CREATE A VIEW WITH A WHERE CONDITION

CREATE VIEW HIGH_SALARY_VIEW AS
SELECT EMPNO, ENAME, SAL
FROM EMP
WHERE SAL > 2000;

Retrieve the data:

SELECT EMPNO, ENAME, SAL
FROM HIGH_SALARY_VIEW;

B. COMPLEX VIEW
----------------

A complex view involves multiple tables or more complex query operations, such as joins, group functions or GROUP BY.

Example:

CREATE VIEW DEPT_SALARY_VIEW AS
SELECT DEPTNO, SUM(SAL) AS TOTAL_SALARY
FROM EMP
GROUP BY DEPTNO;

Features:
1. May involve multiple tables.
2. May contain joins or aggregate functions.
3. Often does not support direct INSERT, UPDATE or DELETE operations.



C. MATERIALIZED VIEW – Oracle SQL Notes
----------------------------------------

Definition

  * A MATERIALIZED VIEW is a database object .
  * Physically stores query results.
  * Can improve performance for expensive queries.
  * Useful for reporting and data warehousing.
  * May need refreshing to reflect changes in the underlying tables.

Syntax

CREATE MATERIALIZED VIEW view_name AS
SELECT column_names
FROM table_name;

Example 1: Create a Materialized View

CREATE MATERIALIZED VIEW EMP_MV AS
SELECT EMPNO, ENAME, SAL, DEPTNO
FROM EMP;

This creates a materialized view named EMP_MV containing the query results.

Example 2: Retrieve Data

SELECT EMPNO, ENAME, SAL, DEPTNO
FROM EMP_MV;

The query retrieves data from the stored materialized view results.

Example 3: Department-Wise Total Salary

CREATE MATERIALIZED VIEW DEPT_SALARY_MV AS
SELECT DEPTNO, SUM(SAL) AS TOTAL_SALARY
FROM EMP
GROUP BY DEPTNO;


Retrieve the results:

SELECT DEPTNO, TOTAL_SALARY
FROM DEPT_SALARY_MV;

How to Refresh a Materialized View

EXEC DBMS_MVIEW.REFRESH('EMP_MV');
